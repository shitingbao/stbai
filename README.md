# 你必须先掌握的 6 个基础名词（逐个说）
## （1）模型（Model / Checkpoint）

你现在做的事情是：

下载一个模型 → 用它生成图

模型 ≈ 画风 + 世界观 + 能力边界

推荐你现在只用这两类：

SD 1.5（老、资源多、ControlNet 友好）

SDXL（新、效果好、未来主流）

👉 建议：现在主力转 SDXL

## （2）Prompt（提示词）

你现在可能觉得：

prompt 就是“写描述”

但真正的理解是：

prompt = 你允许模型做什么

写得越多 ≠ 控制越强

写得越准 ≠ 越复杂

你后面会学到：

prompt 模板化

prompt 只描述“变化的那一部分”

## （3）Negative Prompt（反向提示词）

这是工程化思维的第一课。

正向 prompt：你想要什么
反向 prompt：你绝对不允许出现什么

比如：

多手

崩脸

畸形脚

👉 你以后会发现：
一个好 Negative Prompt，比十行正向 prompt 更重要

## （4）采样步数（Steps）

简单理解：

Steps = 模型“修改噪点”的次数

太少：糊

太多：浪费时间，效果不一定更好

经验值：

SD 1.5：20–30

SDXL：25–40

## （5）CFG Scale（服从度）

CFG = 模型“听不听你的话”

小：自由发挥

大：死板照抄

经验值：

5–7：自然

8–10：偏商业图

## （6）Seed（随机种子）

这是一个非常非常重要的工程概念：

Seed 决定“这张图的基础随机性”

同一个 seed + 同参数 ≈ 同一张图

改 seed = 换一个“平行宇宙”
