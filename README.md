# 你必须先掌握的 6 个基础名词（逐个说）
## （1）模型（Model / Checkpoint）

你现在做的事情是：

下载一个模型 → 用它生成图

模型 ≈ 画风 + 世界观 + 能力边界

推荐你现在只用这两类：

SD 1.5（老、资源多、ControlNet 友好）

SDXL（新、效果好、未来主流）

👉 建议：现在主力转 SDXL

## （2）Prompt（提示词）

你现在可能觉得：

prompt 就是“写描述”

但真正的理解是：

prompt = 你允许模型做什么

写得越多 ≠ 控制越强

写得越准 ≠ 越复杂

你后面会学到：

prompt 模板化

prompt 只描述“变化的那一部分”

## （3）Negative Prompt（反向提示词）

这是工程化思维的第一课。

正向 prompt：你想要什么
反向 prompt：你绝对不允许出现什么

比如：

多手

崩脸

畸形脚

👉 你以后会发现：
一个好 Negative Prompt，比十行正向 prompt 更重要

## （4）采样步数（Steps）

简单理解：

Steps = 模型“修改噪点”的次数

太少：糊

太多：浪费时间，效果不一定更好

经验值：

SD 1.5：20–30

SDXL：25–40

## （5）CFG Scale（服从度）

CFG = 模型“听不听你的话”

小：自由发挥

大：死板照抄

经验值：

5–7：自然

8–10：偏商业图

## （6）Seed（随机种子）

这是一个非常非常重要的工程概念：

Seed 决定“这张图的基础随机性”

同一个 seed + 同参数 ≈ 同一张图

改 seed = 换一个“平行宇宙”

## （7）关键参数：Denoising Strength（重绘强度）

这是 Inpainting 的灵魂。

Denoise = 允许模型“改多狠”

0.2：微调

0.4：明显变化

0.6+：基本重画

经验值：

戴帽子 / 穿袜子：0.3–0.45

## （8）IP-Adapter

IP-Adapter = 让模型“看着一张参考图”生成

不是贴图，不是复制。而是：提取图像特征 → 作为生成条件

🧠 技术本质（人话解释）

Stable Diffusion 原本只能接收：

文本条件（prompt）

IP-Adapter 的作用是：

把“图片”变成条件输入

等价于：

原本：文字 → 影响生成
现在：文字 + 图片 → 同时影响生成
它控制的是：风格，物体特征，颜色，轮廓感觉

但它不控制：精准位置，精准结构，精准贴合

这点非常关键。

🧢 在你的“帽子场景”里

假设：

A 图：人物

B 图：一顶具体帽子

IP-Adapter 可以做到：

让生成的帽子“长得像 B 图”

保持帽子的颜色和材质风格

但它不能保证：

帽子角度完美贴合头型

帽檐精准对齐额头

那是 ControlNet 的事情。

## （9）ControlNet 
ControlNet = 强制模型遵守某种“结构约束”

如果说：

IP-Adapter 控制“长什么样”

那么：

ControlNet 控制“形状和结构”

🧠 技术本质

Stable Diffusion 本质是“概率生成”。

ControlNet 是在生成过程中额外加一条规则：

你必须按照这张结构图生成

结构图可以是：边缘图（Canny），深度图（Depth），姿态骨架图（OpenPose），线稿图

🔧 它控制什么？

人体姿态不变，头部形状不变，轮廓不乱，物体贴合结构

🧢 在你的“帽子场景”里

如果没有 ControlNet：帽子可能浮在空中，帽子压脸，头型被改，头变大

有 ControlNet：头部轮廓锁定，帽子必须贴合头部结构，人物姿态稳定

## （10）三者对比总结（非常重要）
技术	控制什么	不控制什么
Prompt	描述	具体结构
IP-Adapter	参考图风格和特征	精准结构
ControlNet	结构和姿态	风格细节
Inpainting	修改范围	修改内容质量

### （10.1）用工程语言总结

如果你要实现：

人物图 + 帽子图 → 戴帽子的人物

完整逻辑是：

人物图（基础）
↓
Inpainting（限定只改头部）
↓
IP-Adapter（帽子图作为特征参考）
↓
ControlNet（锁定头部结构）
↓
生成

四者各司其职。

### (10.2) 一个更直观的类比

假设你在装修房子：

Prompt = 你告诉设计师“我要北欧风”

IP-Adapter = 给设计师一张参考图片

ControlNet = 房子的结构不能改

Inpainting = 只改客厅，不动卧室

### (10.3)try-on 模型
真正 1:1 精准贴合，是专门的 try-on 模型
比如：IDM-VTON,TryOnDiffusion,OutfitAnyone

优点：专门为换衣设计,更真实

缺点：配置复杂,训练成本高,本地跑麻烦

IP-Adapter + Inpainting + ControlNet
可以达到非常接近的效果。
